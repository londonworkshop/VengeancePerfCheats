# 🎮 Vengeance PerfMonitor — мониторинг производительности для Rust

Актуальная версия с поддержкой последних обновлений Rust. Стабильнее, быстрее, надёжнее.

---

## 🚀 Что это

Vengeance PerfMonitor — это набор скриптов и шаблонов для мониторинга FPS, пинга и задержек в Rust. Проект помогает:

- Замерять производительность в разных локациях и сценариях.
- Выявлять просадки FPS и аномальные задержки.
- Формировать отчёты для подбора оптимальных настроек.
- Сравнивать результаты до и после изменений в конфигах.

> ⚠️ **Важно:** Это не чит и не обходит античит. Утилита не взаимодействует с памятью игры и не модифицирует её файлы. Работает только с внешними замерами и пользовательскими отчётами.

## 🛠️ Установка

1. Скачайте архив из Releases.
2. Распакуйте в удобное место (например, `C:\Tools\VengeancePerfMonitor`).
3. Запустите `loader.exe` для первоначальной настройки.
4. Следуйте инструкциям в консоли.

---

## 🧪 Использование

### Вариант 1: Быстрый замер

Запустите `loader.exe` — скрипт запустит тестовый сценарий и соберёт данные о FPS и задержках.

### Вариант 2: Мониторинг в реальном времени

Запустите `loader.exe` — утилита будет выводить текущие значения FPS и пинга в консоль и сохранять их в CSV‑файл для дальнейшего анализа.

## ⚠️ Предупреждения

- Не используйте эту утилиту на официальных серверах, если правила сервера запрещают любые сторонние инструменты.
